# Vishwas & Madhumitha · Reception Party

The invitation lives at https://vish-vcoder.github.io/Vishwas-Madhumitha/

Personal links greet the guest by name: add `?to=` and the name, for example
`https://vish-vcoder.github.io/Vishwas-Madhumitha/?to=Ananya` or `?to=The%20Sharma%20Family`.

The page is plain HTML (`index.html`) with no build step. Every push to `main` publishes it through
`.github/workflows/deploy.yml`.
